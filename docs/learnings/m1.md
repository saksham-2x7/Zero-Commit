# Learnings (M1: Infra)

* **What I didn't know before:** I didn't realize that EventBridge Scheduler needs the exact physical Lambda function ARN and won't resolve a CloudFormation logical ID seamlessly if the `FunctionName` isn't explicitly defined.
* **What I know now:** When a Lambda is invoked by EventBridge Scheduler, passing the exact `FunctionName` in the SAM template prevents physical ID mismatches.
* **What I didn't know before:** I underestimated how easily circular dependencies can form in SAM when API Gateway, Lambdas, and execution roles reference each other.
* **What I know now:** Breaking the dependency cycle requires manually constructing ARNs using `!Sub` and explicitly naming resources instead of using `!GetAtt`.
* **What I know now:** we planned to restrict PassRole with iam:PassedToService; not applied or verified.
