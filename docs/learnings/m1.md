# M1 Learnings

## What I didn't know before
- How to dynamically pass IAM roles to EventBridge Scheduler (`iam:PassRole`) strictly scoped within an AWS SAM template.
- How to conditionally deploy CloudFront and Origin Access Control (OAC) based on stack parameters in SAM.
- That EventBridge Scheduler supports `ActionAfterCompletion='DELETE'`, keeping the scheduler clean for one-time transactions.

- Fully grasping the 'commit confirmed' pattern applied to AWS resources.
- Building resilient IaC for ephemeral state, ensuring that the IAM policies have exact least-privilege for cross-service invocation.
- Creating shell scripts to automate multi-stage deployments securely without committing sensitive `AuthToken` values.
