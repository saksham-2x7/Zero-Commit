# M3 learnings
- Before: I thought client-side timers were fine; after: countdowns must be driven strictly by server_time to avoid clock drift and false expirations.
- Before: CloudFront routing was assumed static; after: the client must dynamically resolve apiBase from /config.json to support direct API Gateway fallback without path corruption.
- Browser autocomplete treats bearer tokens like passwords; adding autocomplete="off" is essential for clean demo presentation and preventing credential popups.
- In high-stress incident responses, visual clarity is paramount: disabled buttons in terminal states prevent double-clicks, and clear per-operation diffs prevent operator confusion.
- Live EventBridge one-time schedules exhibit real-world jitter (landing ~30s after the timer in one measured run), requiring the UI to gracefully poll beyond 0s rather than assume an instant state flip.
