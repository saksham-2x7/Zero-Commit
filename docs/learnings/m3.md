# M3 Learnings — Frontend (Janani)

## What I didn't know before

- **Server-time based countdowns**: I initially thought about using the browser clock for the countdown, but the spec explicitly specifies `expires_at - server_time`. Relying on client-side time causes clock drift and visual misalignment between the countdown hitting zero and EventBridge actually firing. Driving the remaining duration from `server_time` in `GET /api/changes/{id}` ensures truthful feedback.

- **EventBridge Scheduler jitter & state lag**: In real AWS infrastructure, EventBridge Scheduler one-time schedules have ~1-5s execution jitter (ASSUMPTION-1). The UI must handle the 0s boundary gracefully — when the ring hits 0, it continues polling until the state transition to `REVERTED` / `PARTIAL_REVERT` is confirmed by DynamoDB.

- **Status color psychology under stress**: Revert in Deadman is not always a catastrophic failure — it is the expected safety net when a human does not confirm or triggers manual rollback. Marking normal reverts in bright red confused users into thinking something crashed. Reserving red strictly for `FAILED` and `PARTIAL_REVERT` while using sky-blue/amber for expected rollbacks and emerald green for `CONFIRMED` gives immediate, accurate situational awareness.

- **Selective Mock monkey-patching**: The `VITE_MOCK=1` pattern works by overriding `window.fetch`. However, non-API asset loads (like static `/config.json`) must pass through to native `fetch`. Furthermore, dynamic imports ensure that when building for production without `VITE_MOCK`, mock handlers are completely excluded from the bundle.

- **Per-Op Revert Transparency**: Displaying raw JSON (`{"applied": null}`) after rollback leaves operators uncertain about their Security Group's actual state. Formatting each operation clearly (`REVOKE tcp 80 from 0.0.0.0/0`) with its individual result (`REVERTED`, `SKIPPED`, `FAILED`) from `revert_report` provides instantaneous verification.

## What I know now

- **Accessibility & Keyboard Ergonomics**: On-call operators often navigate using keyboards alone during incidents. Every form control, action trigger (`CONFIRM`, `REVERT NOW`), and dismiss button must have clear focus-visible outlines and intuitive tab ordering.

- **1080p Video Recording Legibility**: High-contrast typography (2.8rem tabular numerical countdown font) and clear status badges ensure that the demo video and screen captures remain crisp and readable at 1080p resolution.

- **Pure System Font & Zero-CDN Constraint**: Relying entirely on native system font stacks (`system-ui`, `-apple-system`, `SFMono-Regular`, `Consolas`) avoids any external Google Fonts or CDN requests, honoring strict zero-dependency hackathon guidelines and zeroing network latency on load.

- **Session Token Isolation**: Storing the bearer token in `sessionStorage` avoids accidental credential persistence on disk or leaks across browser sessions while retaining the token across tab refreshes during testing.
